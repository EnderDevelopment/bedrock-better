# BedrockBetter

BedrockBetter is a Minecraft plugin designed to enhance the Bedrock Edition experience, similar to Better on Bedrock. It provides additional features and improvements to the game, making it more enjoyable and customizable for players. This plugin is compatible with Minecraft Bedrock Edition servers and aims to bring some of the features found in the Java Edition to the Bedrock platform.

## Install

1. Download the BedrockBetter plugin JAR file from the GitHub releases page.
2. Place the JAR file in the `plugins` folder of your Minecraft Bedrock Edition server.
3. Restart or reload your server to load the plugin.

## Use

1. After installing the plugin, players can use the `/ciao` command to receive a greeting message.
